원천징수이행상황신고서 자동 작성 프로그램 — 사용설명서
==========================================================

■ 하는 일
  급여대장 엑셀을 넣으면 선택한 귀속월의
  1) 원천징수이행상황신고서 (소득세법 시행규칙 별지 제21호서식, 한글 HWP 원본 서식에 기입)
  2) 검토용 엑셀 (요약 / 집계근거 / 검토사항)
  을 급여대장 엑셀과 같은 폴더에 만듭니다.

■ 사용 방법
  1. 바탕화면의 "원천세신고서 만들기" 아이콘(또는 이 폴더의 원천세신고서_만들기.bat) 위에
     급여대장 엑셀 파일을 끌어다 놓습니다.
  2. 검은 창에서 귀속월을 입력합니다. (그냥 엔터 = 자료의 마지막 달)
  3. 지급연월을 입력합니다. (그냥 엔터 = 귀속월과 같은 달)
  4. 한글 보안 확인창이 뜨면 "접근 허용"을 누릅니다. (매번 뜰 수 있습니다)
  5. 끝나면 결과 폴더가 열립니다. 검토 엑셀의 "검토사항" 탭을 꼭 먼저 확인하세요.

■ 입력 엑셀 형식 (실습자료와 같은 구조)
  탭 이름에 아래 단어가 들어 있으면 됩니다. 열 순서·제목 줄 수는 달라도 됩니다.
  - "급여대장" 탭 : 귀속월, 성명, 기본급, (수당들...), 지급합계
                    · 기본급 열부터 "지급합계" 열 앞까지를 지급 항목으로 읽습니다.
                    · "식대"는 월 20만원까지 비과세, "자가운전보조금/차량"은 본인차량 업무사용자만 20만원까지 비과세,
                      그 밖의 수당은 과세로 처리합니다.
  - "일용" 탭     : 근무일, 성명, 일당            (없어도 됨)
  - "사업기타" 탭 : 지급일, 성명, 지급 내용, 지급액, 소득구분 (없어도 됨)
                    · 소득구분에 "사업소득" → A25(3%)
                    · "기타소득" 또는 "기타소득(인적용역)" → A59(필요경비 60%, 20%)
                    · "기타소득(그외)" → A42(20%, 필요경비 없음)
  - "고객개요" 탭 : 상호, 대표자, 사업자등록번호, 사업장 (있으면 신고서 상단에 자동 기입)
                    직원 현황 표(성명/입사일/본인 차량)가 있으면 직원정보 기본값으로 가져옵니다.

■ 직원정보 파일 (처음 실행할 때 자동 생성: "상호_직원정보.xlsx")
  급여대장에 없는 정보를 사람별로 적는 파일입니다. 노란 칸을 확인하고 "확인완료"에 Y를 적으세요.
  - 소득구분: 자동 / 상용 / 일용
      자동 = 일용직 탭 근무자가 같은 사업장에 3개월 이상 계속 근무하면 상용(A01), 아니면 일용(A03)
  - 공제대상가족수(본인 포함), 8~20세 자녀수, 원천징수비율(80/100/120)
  - 본인차량 업무사용(Y/N), 식사 현물제공(Y/N)
  새 직원이 생기면 다음 실행 때 자동으로 한 줄이 추가됩니다.

■ 계산 기준 (2025년 귀속)
  - 근로소득 간이세액표: 소득세법 시행령 별표 2 (2024.2.29 개정, 법제처 원문을 그대로 옮긴 간이세액표_2025.csv)
  - 일용근로: (일당 - 15만원) × 6% × 45%, 1일 1천원 미만 소액부징수
  - 사업소득 3%, 기타소득 20% (인적용역 필요경비 60%, 소득금액 5만원 이하 과세최저한)
  - 지방소득세: 소득자별 소득세의 10% (10원 미만 절사) — 위택스에 별도 신고
  - 총지급액: 비과세 포함, 단 자가운전보조금(시행령 제214조 제1항 제2호의3)은 제외
  - 신고·납부기한: 다음 달 10일 (토·일이면 다음 월요일. 공휴일은 직접 확인)

■ 직접 채워야 하는 칸 (HWP)
  전화번호·전자우편, 세무대리인 성명·사업자등록번호·전화번호, 관할 세무서명

■ 하지 않는 것 (직접 처리)
  반기별 신고, 수정신고, 연말정산(A04), 중도퇴사(A02), 퇴직·이자·배당소득, 환급세액 조정,
  연장근로수당 비과세(생산직) 판단 — 해당되면 검토사항에 안내가 나오거나 HWP에서 직접 고쳐 주세요.

■ 해마다 바꿔야 하는 것
  - program\간이세액표_2025.csv : 간이세액표가 개정되면 새 표로 교체
  - program\별지21호_원천징수이행상황신고서_2025.hwp : 서식이 개정되면 법제처/국세청에서 새 서식으로 교체
  - program\wht_report.py 맨 위 "세법 기준값" : 한도·세율이 바뀌면 수정

■ 필요한 프로그램
  한컴오피스 한글(2018 이상), Python(Anaconda) — 이 PC에는 설치되어 있습니다.
